本地视频播放服务-python，http，range

# 具有下面功能
1. 仿照blibli的设计，大体功能都有（播放，暂停，视频翻转，。。）
2. 多线程流程播放


使用方式
一 运行项目
1. 直接运行  python app-v2.py
2. 使用pm2运行项目
![img.png](imgs/img2.png)
